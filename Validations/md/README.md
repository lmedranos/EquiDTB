We investigated the dynamics of four large and flexible molecules: alanine dipeptide, paracetamol, zaprinast, and the ligand 2Q5k. Molecular dynamics (MD) simulations were performed at 300 K for 100 ps, and the resulting trajectories are available in the ZENODO repository associated with this work. For a deeper analysis, 200 representative conformations were selected, and DFT calculations were carried out at the PBE0+MBD level. These results are provided in this directory.

To run MD simulations using EquiDTB models, use the following command line.

```bash
python3 mdrun.py /path_to_model/EquiDTB3.model /path_to_xyz_files/
```
